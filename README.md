# PBXMaison — installation

Installation d'un PBX PBXMaison sur un VPS ou un PC (Debian 12 ou Ubuntu 24.04), en une commande :

```bash
curl -fsSL https://raw.githubusercontent.com/Yoobabab/PBXMaison-install/main/install.sh | sudo bash
```

À la fin, ouvrir l'adresse affichée dans un navigateur : l'assistant demande le fichier `pbx-config.json` téléchargé sur le portail, puis tout se règle dans la console web.
